# E.T. Remastered

**E.T. The Extra-Terrestrial: Remastered** — a playable browser remaster of the 1982 Atari classic.

Stranded in the moonlit forest, E.T. must explore 6 sectors, descend into wells to recover the 3 interplanetary phone pieces, eat Reese's Pieces to keep his Heartlight glowing, avoid the agents, and signal the mothership.

## Play

**[Play it now on GitHub Pages](https://waggy44-jpg.github.io/ET-Remastered/)** — no install needed. Works with keyboard or on-screen touch controls.

## Controls

- **WASD / Arrow keys** — Walk (hold **Shift** to move faster)
- **Spacebar** — Finger glow: scan, levitate, and float out of wells
- **E** — Eat a Reese's Piece (+850 Heartlight)
- **T** — Run the built-in diagnostics (QA)

## About

A single self-contained `index.html` built with Three.js (isometric 3D), Tone.js (synthesised audio), and Tailwind CSS. No build step — open `index.html` or serve the folder with any static host.
